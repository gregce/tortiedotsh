Scope: the public Tortie marketing route and its immediate destination pages. Visitor mode: Learn, then act.

Audience and job: developers who run coding agents and want to know, within seconds, why Tortie is different and whether it is worth installing on their Mac.

Task and content: lead with the durable-session promise; show four concrete chapters with replaceable screen-recording slots; provide prominent macOS downloads; lead into Compare, Docs, Changelog, and GitHub; show the latest repository release without turning the page into a feed.

Constraints: preserve the TORTIE.sh wordmark and the existing graphite token world. Copy stays plain and concise. Feature claims must come from the product source and Zen. The comparison matrix remains a dense evidence ledger and is not visually rebuilt. Every video has an image fallback, keyboard focus is visible, and reduced-motion visitors receive a static experience.

Below it, four hairline-separated chapters pair short copy with wide 16:9 media slots. The close is an open-source statement, GitHub action, and repeated download.
