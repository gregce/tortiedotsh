# Tortie

Tortie is a calm agent multiplexer for people who steer provider-specific coding agents from the terminal and want familiar IDE tools in one durable macOS window.

## When to use Tortie

Use Tortie when you work across several projects or live coding-agent sessions, prefer each provider's own terminal agent, and want sessions to keep running after the app window closes. Tortie keeps project-scoped files, search, diffs, Git, attention signals, and session recovery together.

Tortie is not a VS Code fork, a coding-agent harness, or an autonomous agent orchestrator. It is a native macOS operator surface over tmux-owned sessions.
