# Pixel Tortie illustration family

Ten original 16-bit-style illustrations generated with the built-in GPT Image 2 workflow for Tortie.sh.

The visual system uses the production Tortie mark as the character anchor: a seated black cat viewed from behind, with the electric-blue seam geometry preserved. The world stays near-black, navy, moss green, and cyan. Amber appears only when a session needs human attention.

## Assets

1. `01-session-forest-wide` — the world anchor: durable agent lights moving through one forest.
2. `02-survive-quit-wide` — work continuing beyond a closed window.
3. `03-one-project-window-wide` — separate paths gathered into one workspace.
4. `04-what-needs-you-square` — one amber signal among quiet blue agents.
5. `05-restore-conversation-square` — a dormant trail relighting in place.
6. `06-jump-to-session-wide` — the surfaced route to a waiting session.
7. `07-remote-tmux-bridge-wide` — a private, durable bridge between machines.
8. `08-source-control-square` — branching and merging paths with a clean green point.
9. `09-open-source-grove-wide` — many paths contributing to a shared grove.
10. `10-mascot-accent-square` — a transparent small-format mascot with blue and amber fireflies.

Full-resolution PNG masters live in `source/`. Web-ready AVIF and WebP derivatives live in `public/illustrations/pixel-tortie/` and are the only versions referenced by the site.

`contact-sheet.webp` provides a quick view of the full family in filename order.

## Prompt system

Every image used three references: the Tortie mark for identity, the supplied luminous 16-bit forest for atmosphere, and asset 01 as the family continuity anchor. Prompts required crisp square pixels, deep black edges that blend into the site, a restrained palette, no text or watermark, and no changes to the cat silhouette or blue seams. Each scene then expressed one product concept through forest paths and agent lights.
