## Shared prompt constraints

- Required navigation: TORTIE.sh, Compare, Docs, Changelog, GitHub and Download for macOS.
- Required story: sessions survive the window, projects remain coherent, and only work
  needing a human asks for attention.
- Palette: Tortie's graphite surfaces, cool white and gray text, blue action, and amber
  only for a real needs-input or limited state.
- No testimonials, star counts, pricing, invented metrics, aggregate comparison score,
  generic SaaS card wall, decorative gradients, glassmorphism or neon.
- Full-page concepts use the `ui-mockup` prompt class. The hero uses
  `stylized-concept` and requests a true 16:9 cinematic plate with no embedded copy.
